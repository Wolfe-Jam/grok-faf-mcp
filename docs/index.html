The first MCP server for Grok. It reads your IANA-registered project.faf and hands Grok the stack, the goal and the rules — scored always-33, the same number faf-cli gives.

Use the hosted URL
~/.grok/config.toml 
# one line — then restart Grok (or /mcps r)
[mcp_servers.grok-faf-mcp]
url = "https://mcpaas.live/grok/mcp/v1"

❯ faf_score project.faf
  score  100%  tier  Trophy ✪
  slots  33 of 33 filled (populated or slotignored)
❯ refresh_faf
  re-read + re-scored mid-session — re-grounded
